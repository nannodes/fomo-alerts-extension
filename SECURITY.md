# Security

Found a security problem in FOMO Alerts (the Chrome extension, the website or the Telegram bot)? Please tell us **privately** first, so we can fix it before anyone misuses it:

- Use **"Report a vulnerability"** on this repository's **Security** tab, or
- email **support@fomoalerts.family** with "Security" in the subject.

Please say what you found and how to reproduce it. Don't test it on other people's accounts or data. We'll reply within a few days, and credit you once it's fixed if you like.

**Found a fake FOMO Alerts** (an extension, bot, account or coin)? Check the official list at [fomoalerts.family/dont-get-scammed.html](https://fomoalerts.family/dont-get-scammed.html) and tell us on [Discord](https://discord.gg/RxWRnQNYMx).
